# 🏥 Dashboard de Gestión Comercial e Inventario - Sector Farmacéutico

Aplicación web interactiva desarrollada en Python para el análisis de indicadores de venta, volumen despachado y gestión de inventario en empresas de distribución farmacéutica.

## 🚀 Características Principales

- **Tarjetas KPI Ejecutivas:** Resumen inmediato de Ventas Totales ($), Unidades Vendidas, Ticket Promedio y Productos en Alerta Crítica (< 50 unidades).
- **Gráficos Interactivos (Plotly):**
  - Análisis de ventas consolidadas por categoría terapéutica.
  - Monitoreo de niveles de stock por producto con alerta visual de inventario crítico.
- **Filtros Dinámicos:** Selección por categoría en la barra lateral que actualiza métricas y gráficos en tiempo real.
- **Exportación de Datos:** Módulo dinámico para descargar el reporte filtrado directamente a un archivo de Microsoft Excel (`.xlsx`).

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Python 3.x
- **Librerías principales:**
  - `streamlit` - Interfaz gráfica e interactividad web.
  - `pandas` - Manipulación y transformación de datos.
  - `plotly` - Visualización gráfica interactiva.
  - `openpyxl` - Generación y descarga de archivos Excel.
